# Credits

## Original project

GLemples is a browser/WebGL port of **Drempels**, the real-time image-warping
desktop visualiser created by **Ryan Geiss**.

- Author: Ryan Geiss
- Project: Drempels — <https://www.geisswerks.com/about_drempels.html>
- Website: <https://www.geisswerks.com/>

The seven-mode UV warp at the heart of this project (`src/engine/warp.ts`) is a
direct port of Drempels' original warp algorithm. The 'Geiss' mode names and
behaviour come from that work unchanged. All credit for the core visual effect
and its mathematics belongs to Ryan Geiss.

Ryan Geiss released the Drempels source under the GNU General Public License, so
this port is distributed under the GPL as well (see [LICENSE](LICENSE)).
